SQLGuardian

Ask the AI why your server is slow. Get a T-SQL fix back in seconds.

AI-powered SQL Server health monitoring platform. Runs 7 DMV-based checks every 60 seconds — blocking chains, wait stats, agent jobs, disk, backups — and feeds live telemetry to an LLM that explains incidents in plain English, generates remediation T-SQL, and answers natural-language questions grounded in real server data, not guesses.

Detects live blocking with head-blocker session IDs and locked SQL. The AI names the blocker, weighs the safe options, and explains the trade-offs before anything destructive. Dual-audience output: a technical DBA view and a one-paragraph management summary from the same snapshot.

QueryLens

Ask in English, audit any query, and grade the LLMs that write SQL.

A SQL workbench with a read-only safety boundary, built on the DBA instinct that nothing should ever touch production without guardrails. Three pillars: Ask turns natural language into SQL and runs it live; Analyze scans a query for anti-patterns, scores it, and rewrites it; Evaluate benchmarks LLM-generated SQL against gold answers.

Every statement passes through a sandbox that rejects writes, DROPs, and multi-statement input before it reaches the database.

FlowLens

The pipeline said "Succeeded." It still dropped a third of your rows.

An AI-native data reliability platform for SQL Server ETL. A stored proc can finish with zero errors, log Succeeded, and silently drop 38% of its rows to one bad JOIN. FlowLens sits between staging and production as a Write-Audit-Publish gate and refuses to publish a batch until it clears data contracts, source-vs-target reconciliation, and an IsolationForest anomaly check.

The design line I care about: the AI never decides pass/fail. Every verdict is deterministic SQL and statistics — the LLM only writes the plain-English incident report, grounded in the exact evidence the gate collected.
