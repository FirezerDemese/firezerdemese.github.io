SQLGuardian

Ask the AI why your server is slow. Get a T-SQL fix back in seconds.

AI-powered SQL Server health monitoring platform. Runs 7 DMV-based checks every 60 seconds (blocking chains, wait stats, agent jobs, disk, backups) and feeds live telemetry to an LLM that explains incidents in plain English, generates remediation T-SQL, and answers natural-language questions grounded in real server data.

Detects live blocking with head-blocker session IDs and locked SQL. The AI names the blocker, weighs the safe options, and explains the trade-offs before anything destructive. Dual-audience output: a technical DBA view and a one-paragraph management summary from the same snapshot.

QueryLens

Ask in English, audit any query, and grade the LLMs that write SQL.

A SQL workbench with a read-only safety boundary, built on the DBA instinct that nothing should ever touch production without guardrails. Three pillars: Ask turns natural language into SQL and runs it live; Analyze scans a query for anti-patterns (SELECT *, leading-wildcard LIKE, missing filters), scores it, and rewrites it; Evaluate benchmarks LLM-generated SQL against gold answers.

Every statement passes through a sandbox that rejects writes, DROPs, and multi-statement input before it reaches the database. The eval and rewrite work is grounded in real query plans, not vibes.
