SQLGuardian

Ask the AI why your server is slow. Get a T-SQL fix back in seconds.

AI-powered SQL Server health monitoring platform. Runs 7 DMV-based checks every 60 seconds — blocking chains, wait stats, agent jobs, disk, backups — and feeds live telemetry to an LLM that explains incidents in plain English, generates remediation T-SQL, and answers natural-language questions grounded in real server data.

Detects live blocking with head-blocker session IDs and locked SQL. The AI names the blocker and writes the KILL script. Dual-audience output: a technical DBA view and a one-paragraph management summary from the same snapshot.
